## Native64 结论

原 Native384-v8 分支采样 44 张切片，遍历 42 个三切片窗口。本实验增加到 64 张、62 个窗口，保持 6%–94% 覆盖范围、模型权重、分辨率、裁剪与融合比例不变，其余三个 Raptor 分支也不变。

只增加窗口参数不会产生新的切片信息，原缓存已经看全。因此本实验测试的因素是采样密度。双 T4 禁网运行成功、必需分支完整，实际公榜下降 0.001；没有支持继续推广此改动的证据。该结论针对这个分支和配方，不代表密集采样普遍无效。

原版与候选可见 test 均只有 3 例。运行耗时约 205 秒和 171 秒主要混合了启动与小样本成本，不能据此宣称新配置更快。

## Stage 5A 与验证限制

Stage 5A coarse 的 58 例开发 AUC 为 0.878387。导出父模型在同批病例为 0.954846，加入 2% coarse 后仅为 0.954967；配对 bootstrap 增益区间跨零，加入 5% 后下降至 0.954504。暂停这条全类别融合路线。

58 Gold 已参与历史选择；新基线残差 CoAtNet 回执明确以 Gold58 选择 checkpoint。因此该集合只能用于开发诊断，不能称为新基线的独立验证集。父模型历史提交与导出版本的精确对应亦存在先前记录的限制。
