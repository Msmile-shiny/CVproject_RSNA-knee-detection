# Stage 6：持续优化一条训练主干，而非再换一个模型名

2026-09-24。当前可靠 Public 基线为复刻 Anchor942（0.942）。Fracture 单变量提交 56514045 仍 PENDING。本计划不替代或覆盖父模型。

## 为什么之前停止了，哪些停止理由不充分

| 实验 | 已经证实的事 | 没有证实的事、决策修正 |
|---|---|---|
| Stage 3A/B/C | 整套新监督相对旧监督明显下降；裁剪差异较小 | 概率、权重、mask 同时变化，不能说某个 LLM 不行。停止整套替换合理，未完成逐组件诊断 |
| 早期v6a RadImageNet R50 | 代码明确unfreeze_layers=0，只训练SlotHead | 我们确实做过ResNet，不应把换成ResNet当新发现。本轮关键差异是卷积骨干端到端训练、固定折与连续诊断，而不是34与50的数字不同 |
| Stage 3D | 排序只在27.9% batch生效，Public .880；与原模型高度相关 | 随机小batch没充分测试可信配对；不能否定所有排序学习。先不在弱骨干继续加损失 |
| Phase4A/4A2 | 冻结 OrthoFoundation 探针低分；4A训练仍在改善 | 没测完整微调，把探针门槛当路线生死线过早。暂停是预算决定，不是证明医学预训练无效 |
| Stage5A | 冻结旧DINO特征，密集MIL未证实父模型融合收益 | 没检验端到端密集训练、真实解剖ROI；注意力选片不是病灶定位。曾有超时工程问题，不能与算法失败混为一谈 |

共同问题：新骨干、监督和输入曾一起变化；弱单成员直接和大型融合比较；开发集过小且多次复用；没有稳定续跑与明确的诊断预算。过去报告里“停止该路线”的措辞超出了实际证据。对此负责的是实验设计，不是用户没有耐心。

## 本次主干与边界

选择 **torchvision ResNet-34 + 多序列2.5D聚合**：约2180万参数，已有官方ImageNet权重，容易端到端训练；未来可复用编码器做密集覆盖、序列注意力和局部解剖辅助任务。2.5D即真实相邻三张切片放入三个输入通道，不是完整三维卷积。

这不是承诺ResNet34胜过所有模型，也不是公开0.936小ResNet方案的精确复刻（作者未公开完整配方）。社区报告说明小CNN具有竞争潜力，无法证明本配方必达相同成绩。

第一轮是**新的参考起点**，不是与v5只差一个变量的因果实验。后续才以它为固定对照。

- 六种既有序列槽位；每槽4个位置覆盖完整深度，每个位置真实相邻三张；224px，保留完整视野和物理纵横比。首先测试低成本参考，不称密集64/96切片方案。
- 全骨干可训练；小batch冻结BatchNorm运行均值，不冻结卷积参数。首轮均值聚合，暂不加注意力/排序/ROI/新伪标签。
- 固定历史v5标签及哈希，目的仅是隔离新训练主干；旧标签曾利用Gold校准，图像教师OOF来源未完全验证，不能称无泄漏验证。
- 按PatientID分组（若元数据没有则退回Study UID并在收据明示，不能声称患者级隔离）。固定哈希5折，首轮只跑fold0；不按结果重新分组。
- 留出伪标签病例用于检查拟合与泛化趋势，不是临床真值。Gold只作开发结果展示，不选择checkpoint/epoch。保存最后一轮与优化器/RNG。
- 单GPU batch1减小首次OOM风险。smoke记录时间后决定正式预算；不因GPU闲置就启动多折。
- 离线权重严格加载，数据解码失败显式报错，不悄悄丢病例。研究训练的fail-fast与比赛隐藏推理的fallback是不同用途。

## 必须完成的连续实验，而非一次掉分就改主干

1. **6A-smoke**：8训练+4伪验证+4Gold，1epoch；检查梯度、mask、解码、分组、磁盘/耗时。它没有成绩意义，禁止提交排行榜。
2. **6A-reference**：同模型fold0，smoke=False，预先定12epoch、480分钟预算（运行超时可续跑）。输出训练曲线、伪验证预测与Gold逐例预测。预算不是承诺一定12轮跑完。smoke->正式是新运行，不能加载smoke权重。
3. **6B-optimization**：如训练损失仍明显下降，原样续训至24轮；如拟合不足，单独做骨干学习率×3对照（其余不改）。这是最多两项诊断预算，不是无止境坚持。不得只看一个Gold点决定放弃。
4. **6C-supervision**：在相同fold、输入和训练预算下替换一种经来源审核的报告监督。明确阳性/阴性/未提及/不确定分开记录。没有可核实逐折排除信息时，不把公共图像教师称作OOF；首轮不再全套改概率+权重+mask。
5. **6D-coverage**：独立增加4->8位置，或独立更换均值->分类注意力，不在同一试验一起改变。像素缓存容量须重新测算，不能假定Kaggle磁盘够用。
6. **6E-fusion**：父模型Gold预测严格对齐；只预注册小权重2%/5%，先检查错误是否改善。开发集证据有限，最多一次候选Public验证，不扫描几十个权重。确认正收益再扩展多折，而不是堆seed。

终止标准：完整训练能拟合、输入和标签审计通过、完成上述预算内的优化诊断及一个监督对照后，仍持续弱且对父模型没有互补证据，则带着归因报告暂停。不要求把所有创新都做一遍才允许停止。工程报错先修工程，指标下降先区分欠拟合、过拟合和错误监督。

## 文献创新如何接在同一主干上

- CoPAS：同平面不同序列的信息对应；下一研究扩展可增加序列间注意力，但当前mean聚合不是CoPAS复现。先证明多序列覆盖可靠，再加复杂交互。
- 解剖定位多任务：用可信定位标注或独立验证的定位器监督局部表示；保留全局上下文。不直接把attention热图当真病灶。先有错误分布才选半月板或其他类别。
- 可信配对：保留Stage3D想法，未来改成保证有效配对的采样或跨batch队列；要求观测每类实际配对数。当前不再把稀疏配对叠加到新基线。
- OrthoFoundation/OrthoDiffusion：保留为后续表示学习研究；当前缺乏算力与收益证据，不同时开第二条训练主线。
