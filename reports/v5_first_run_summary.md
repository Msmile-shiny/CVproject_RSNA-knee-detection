## 二、与 0.91 notebook 的差异对比（概念阐释）

### 2.1 单模型 vs 集成 —— 偏差-方差分解

**概念**：一个模型的预测误差 = 偏差²（全体模型的平均预测离真值的距离，由假设空间决定）+ 方差（单个模型相对平均预测的抖动，由训练随机性/优化路径决定）+ 不可约噪声。**集成平均 N 个独立模型能把方差降到 1/N**，偏差不变——所以集成几乎总是涨分，且成员越独立（不同骨干/分辨率/标签源）方差削减越彻底。

**他们**：24 成员公开权重 + A5 折模型 + RadImageNet + 专家，0.91 = 单成员水平（~0.85-0.88）+ **集成红利（+0.03~0.06）**。

**我们**：一个模型 gold 0.8904 / LB 0.881。红利还没领。

### 2.2 rank 融合 —— 为什么全程用 rank 而不用 prob

**概念**：竞赛指标 macro ROC-AUC **只关心研究间的排序**，不关心概率的绝对校准。不同成员训练目标/尺度不同（软标签、硬标签、不同损失），prob 直接平均会被"输出方差大"的成员绑架投票权。`rank(pct=True)` 把每个成员压缩到 [0,1] 均匀分布——所有成员对排序贡献等价，融合结果天然与 AUC 同构。这是 0.9+ 公开方案的标准操作。

**他们**：`_combine` 先逐列 rank 再加权；A5/Rad15/专家替换全部在 rank 空间进行。

**我们**：目前单模型不需要融合；但 v5 规划 ⑤（OOF rank 融合）就是这套，届时照抄他们的权重形式即可（member×target 双权重）。

### 2.3 专家 rank 替换 —— 多模态互补

**概念**：融合收益 ∝ 成员间**互补性**（complementary information）。同构模型（同为 DINOv2+SlotHead）重复 20 遍，方差削减会饱和；而报告文本、radiomics 手工艺特征是**异质信号源**——主模型（图像+伪标签）学不好的弱类，异质专家可能恰好擅长，用高权重（0.75-0.875）在 rank 空间**替换**该列的排序。这与"平均"不同：替换 = 承认主模型在该类上不可信。

**他们**：Synovitis ← report-teacher 文本模型（0.75）；Lateral Meniscus/Lateral OA ← radiomics 专家（0.5-0.875）。

**我们**：这正是 v5 规划 ⑥ 的 Synovitis specialist（RTAHMIL 蓝本 +0.084）——**他们的实盘做法验证了我们的规划**。

### 2.4 头的信息瓶颈 —— SlotHead vs token 级跨注意

**概念**：池化（pooling）是把 N 个 token 压成 1 个摘要向量的**有损压缩**——病灶的精确位置、大小在池化中被抹掉，只留"有没有"。12 个 finding 各需不同的空间证据（半月板撕裂 vs 骨挫伤 vs 囊肿位置），摘要向量无法同时保留全部。**token 级跨注意**则让每个 finding 的 query 直接读全 study 每个 token（key-padding 掩缺槽），定位信息无损。

**他们**：新增 DINOv3 成员 = 类型 token 嵌入 + 12 query 对全 study 拼接 tokens 做 MHA + mean/max CLS 拼接；report-teacher RTAHMIL 同构。

**我们**：SlotHead = 先 per-slot 池化再共享 query 注意力——存在同一瓶颈。**注意：他们的主成员也是 SlotHead，说明这个瓶颈不是 0.83→0.89 的来源，而是 0.89→0.90+ 的潜在空间**（v6 换头方向）。

### 2.5 per-target TTA 池化 —— 病理空间先验

**概念**：TTA 对多个窗口/视图的预测做池化，本质是问"该 finding 的证据如何跨窗口聚合"。病灶空间分布是领域先验：**骨折/挫伤**单窗口即可决定性（单帧断裂）→ 用 **max**；**韧带**在 3D 上连续跨多窗口（不能只有一帧撕裂）→ 用 **top2 平均**抗噪；**滑膜炎**易受单帧噪声 → 用无 jitter 原始视图平均。把这个先验编码进推理，几乎零成本。

**他们**：Fracture/Contusion/半月板/Baker's → max；ACL/MCL → top2；Synovitis → original_mean。

**我们**：核对后发现 v5 代码**早已内置同款池化表**（Fracture/Contusion/半月板/Baker's → max、ACL/MCL → top2、其余 mean——**0.8904 实跑已启用**，与他们的表逐项一致）。2026-08-14 已补上另一半：**jitter 增广视图**（每个窗口一个确定性增广视图，视图概率平均后再做窗口池化，Synovitis 按他们的 `original_mean` 只用原始视图），见方向 1。

### 2.6 软标签 vs 硬标签 —— 蒸馏的软目标思想

**概念**：知识蒸馏中 soft target（概率向量）比 one-hot hard target 携带更多信息——0.7 和 0.9 的 teacher 输出教会学生"这个样本的置信梯度"。同理，伪标签管线的硬二值化会丢弃 teacher 的不确定性，并在 0.5 阈值附近制造大量标签噪声。**软标签 + 置信度权重**保留梯度信息，且让模型对 teacher 的不确定样本自动降权。

**他们**：训练路径用 pilkwang 报告表**硬标签** + conf 权重（gold 权重 3.0）——半软近似。

**我们**：融合软标签（文本 × OOF teacher 的 per-finding 逻辑回归）+ WeightedSoftBCE——**理论上更优，0.8904 超预期的一部分原因可能在此**。

## 三、未来提升方向（按性价比排序）

### 方向 1（已完成 2026-08-14）：per-target TTA 池化 + jitter 增广视图
移植前核对发现：per-target 池化 **v5 原本就有**（`DIAG_POOL` 与他们的 `TTA_TARGET_POOL` 逐项一致，0.8904 实跑已启用）。本次补上缺的另一半——**jitter TTA**：每个窗口额外生成一个确定性增广视图（旋转 ±8° / 缩放 +8% / 平移 ±5% / 强度 ±10%，即 0.91 的 `augment()` 同款），视图概率平均后再做 per-target 窗口池化；Synovitis 按他们的 `original_mean` 只用无 jitter 原始视图。已接入三处推理（验证选模、gold 验证、测试提交），本地冒烟全过，下次实跑随 notebook 生效。预期：TTA 方差削减的小幅正收益（他们 0.899→0.909 公开经验里的同类技巧贡献），实跑在 gold 上验证。

### 方向 2（已完成 2026-08-15）：⑤ 3-5 seed 自集成 + OOF rank 融合
**概念**：seed 集成 = 同一 pipeline 换随机种子，训练路径/数据完全相同，成员"半独立"（共享数据但优化路径独立）——方差削减幅度低于异质集成但远高于单模型。再加 OOF：每个 seed 留 5% gold 做 out-of-fold 预测，在 4407 训练研究上构造全量无泄漏的元特征，用于学习 per-target 融合权重（他们 legacy bundle 的 target-specific weight 同款手法）。
**结果**：三成员 rank-mean 融合 gold 0.8959 / LB 0.886（+0.005）。两两相关 0.959-0.966，同构 seed 红利已尽。**OOF 权重学习未做**——58 gold 太少，学权重必过拟合，rank-mean 等权已是最稳解。

### 方向 3（已裁决归档 2026-08-15）：⑥ 文本强类专家成员（原 Synovitis 专家改道）
**概念**：见 1.5 探针——文本词表提取器（规则型、无泄漏）在 **ACL/MCL/Lateral Meniscus/Lateral OA** 上显著强于图像成员（gold +0.028~+0.093），而 Synovitis/Effusion 是图像强类。测试集无报告文本，文本信号只能走训练期蒸馏：**训练一个以纯词表软标签（report_labels_v2）监督的专家成员**（同 SlotHead 架构换标签源，~2h），推理时按 0.91 的 `0.75·rank(主) + 0.75·rank(专家)` 只替换这 4 类，其余类保持图像融合。
**实跑结果（kaggle_train_v5spec.ipynb）**：训练健康（val 0.8597 ≈ gold 0.8606），但蒸馏折损过大——词表上限 ACL 0.953/MCL 0.964/LM 0.846/LOA 0.839 只恢复出 **ACL 0.8922**（唯一赢过 3-seed 融合 0.8854 的类），MCL 0.8707/LOA 0.7853 反输，宏 0.8606 vs 0.8958。
**融合扫描（scripts/fusion_scan_spec.py，58 gold，CPU）**：4 类 0.75/0.75 替换 = **-0.0023**（MCL -0.0295 拖累）；仅 ACL 替换 = +0.0004（w 任意——rank 混合整体缩放不改变排序）；spec 作第 4 成员（最佳 w=0.15）= +0.0003；逐类 oracle 上限 = **+0.0011**——连作弊上限都低于 +0.003 阈值。
**裁决：归档，融合端禁用**（cells_infer_v5/08_infer_fusion.py `SPEC_REPLACE_TARGETS=[]`，扫到 best_model_spec.pt 只打印诊断 AUC；notebook 已重建，CPU 重放验证 FUSED==BASE）。
**教训**：词表强类的文本信号大部分在像素中不存在（报告含图像没有的信息，如临床病史），图像蒸馏不可恢复；RTAHMIL +0.084 先例是报告模型直接读文本、不是图像蒸馏。测试端无文本 → 文本路线没有图像端出口，封死。

### 方向 4（1 个会话）：⑦ 多样性分支
**概念**：见 2.1——集成收益 ∝ 成员独立性。加一个**异质骨干**（EfficientNet-B3 2.5D，或 RadImageNet ResNet-50 冻结编码器 + 小头）比第 6 个 DINOv2 seed 更值钱。他们 Rad15 段全套可参考（5 折头 + rank 平均 + α=0.35，Baker's/Fracture 排除）。
**预期**：+0.005-0.01。

### 方向 5（v6 换头实验）：token 级跨注意头
**概念**：见 2.4。把 SlotHead 换成 RTAHMIL/TokenXAttnPool 结构（12 query 对全 study tokens 的 MHA）。这是架构级改动，需要离线实验对比后再上 Kaggle（冒烟测试即可验证实现正确性）。
**预期**：不确定（他们主成员也用 SlotHead 拿到 0.89+），作为 v6 候选而非必选。

### 方向 6（条件性）：336px + 双分辨率
**概念**：分辨率冗余——同一研究在 224/288/336 三个采样率下的信息互为补充（高频细节 vs 上下文）。他们 r224+r336 rank-mean 是验证过的组合。代价：缓存内存翻倍（336px 缓存 26.7GB），需 T4x2。我们的 288px 已满足奈奎斯特，此项优先级低于 1-4。

### 方向 7（工程）：report-hash 去重 holdout + 权重契约
OOF/自集成分割时用他们 `MD5(report) % 5` 手法防止同一报告跨 fold 泄漏；多成员阶段再移植 fingerprint/SHA256 契约。纯工程，不涨分但防事故。
